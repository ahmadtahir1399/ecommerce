# E-commerce storefront

A product page and cart built with Next.js. It covers the parts of a store that take the most UI work: choosing options,
reading reviews and managing the cart.

## Features

- Product gallery with size, color and quantity selectors
- Product details in tabs, with a description and customer reviews
- Review form with validation
- Slide-out cart with item controls
- Responsive header and navigation

## Stack

Next.js · React · TypeScript · Tailwind CSS · shadcn/ui (Radix) · React Hook Form · Framer Motion

## Run it locally

```bash
git clone https://github.com/ahmadtahir1399/ecommerce.git
cd ecommerce
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The product page is at `/order`.

This is a frontend project, so products are sample data and there's no checkout or payment step.
